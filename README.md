# Abdul Ahad - Portfolio Website

Personal developer portfolio for **Abdul Ahad** — MERN Stack Developer & Flutter App Developer.

## Tech Stack
- **Framework**: Next.js 16 (React 19)
- **Styling**: Tailwind CSS & Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript

## Features
- Dynamic showcase of web projects (Aam E Khas, Phishing Simulator, Duct Care Expert, Edenrobe Clone) & Flutter Mobile Apps (Qibla Direction & Prayer Time App).
- Fully responsive design with dark mode accents, smooth scrolling, and micro-animations.
- Directly integrated contact links (Email, WhatsApp, GitHub, LinkedIn, Instagram).

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the portfolio.
